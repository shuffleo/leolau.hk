# Writing Artwork Descriptions

Turn raw notes, drafts, and conversations into website-ready artwork descriptions.

## Default Voice & Balance

- Concept first, then experience, then mechanism only if needed
- Artist voice — not curator, not institution
- 70% accessible, 30% theoretical
- Clear, layered, open-ended
- Hint of artist statement, but still a website text
- Leave room for interpretation

## Output Format

**Length:** 120–220 words, 1–2 short paragraphs.

**Optional metadata block at top:**

```
Title
Year
Medium / duration / dimensions
```

**Structure (follow this order):**

1. What the work is concerned with
2. How that concern appears in the work
3. What the viewer encounters
4. How material/process matters
5. End without fully closing meaning

Do **not** start with technical setup unless it is central to the idea.

## Writing Rules

**Prefer:**

- Clear opening sentence
- Concrete language
- Active verbs
- Specific tensions, conditions, relations
- Grounded abstraction
- Locating presence, risk, and judgment — where the artist's hand actually is

**Avoid:**

- Press-release tone
- Curatorial jargon
- Generic phrases: "explores the intersection of", "challenges perceptions", "invites viewers to reflect", "blurs boundaries"
- Overexplaining
- Sounding too academic or too promotional
- Performative depth — text that signals substance without delivering it
- The "tool narrative" — reducing a medium to "made with X" or "created using Y"

## When the Work Uses AI or Computational Processes

- Describe what the system *does* to the work (its biases, defaults, tendencies) — not just that it was used.
- Foreground what the artist chose, kept, refused, or redirected.
- Don't flatten to "made with AI" or "created using [tool]."
- If multiple agencies are at play (artist, model, dataset, culture), let the description hold that — don't reduce it to a credit line.
- If the work sits between human control and machine tendency, let the text sit there too.

## Extracting from Raw Materials

When the user gives notes or drafts, identify:

1. Core concept
2. Viewer experience
3. Material / process — and the artist's relationship to it
4. Larger stakes
5. Whether this is a single work, part of a series, or part of an ongoing practice
6. Where human presence, risk, and judgment enter the process

## When to Ask Clarification

Ask **only** if one of these is unclear:

- What is the main idea of the work?
- Is this a single work, series, or part of a larger practice?
- What does the viewer encounter first?
- Does the process/technology need explaining?
- Should the tone be more clear / reflective / minimal?
- Short or longer version?

Ask **2–4 short questions max** before drafting.

**Ask direct, high-yield questions like:**

- "What is the central tension in this work?"
- "Is this a standalone piece or part of a series?"
- "What should the reader understand first: the idea, the experience, or the system?"
- "What part do you want to leave open rather than explain?"

## Handling Messy Notes

Do **not** ask the user to reorganise. Instead:

1. Summarise what seems to be the core idea
2. Give 2–3 possible framings
3. Ask the user to choose or refine
4. Then draft

Use prompts like:

- "This seems less about X and more about Y. Is that right?"
- "I see three possible directions here…"
- "Should this foreground concept, encounter, or wider practice?"

## Workflow

1. **Extract:** concept, experience, mechanism, stakes, practice context
2. **Identify** what is missing
3. **Ask** only necessary questions
4. **Draft**
5. **Revise** if needed

## Revision Modes

Be ready to revise into:

- More accessible
- More precise
- More artist-voiced
- Less theoretical
- Shorter
- More open-ended
- More connected to series/practice

## Red Flags — Fix If the Draft…

- Starts with mechanism instead of concept
- Sounds like a curator wrote it
- Is too vague or could describe any artwork
- Explains too much
- Uses too much jargon
- Lacks image, experience, or tension
- Performs authenticity — sounds deep but says nothing specific
- Reduces the medium to a tool credit
- Resolves ambiguity the work deliberately keeps open

## Default Instruction

Write a concept-led, artist-voiced website description that is clear, layered,
balanced, and open-ended. Start with the work's central concern, ground it in
the viewer's encounter, include process only where it adds meaning, and avoid
over-explaining.
